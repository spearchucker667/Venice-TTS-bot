# Support

- Reproducible bugs belong in GitHub Issues, using the bug form, once the repository exists.
- Usage questions do not have a Discussions board. This project has not enabled Discussions. Do not file a bug only to ask how Venice billing works.
- Vulnerabilities do not belong in public issues. See [SECURITY.md](SECURITY.md).
- There is no private support email and no paid support channel.

[docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md) covers the failures the app already reports.
