# Roadmap

No dates.

## Shipped in the current tree

- Streamed Venice chat with a system prompt and character blend modes
- Catalog refresh for text, speech, hearing, traits, characters, and compatibility hints
- Sentence-level speech playback with an MP3 audio fallback
- Speech-to-text microphone path and hands-free turn-taking with VAD hysteresis and ambient calibration
- Voice Changer quote, single queue, retrieve, and complete
- Local chat list with pin, rename, delete, export, import, search, and message branching
- Generation presets (temperature and top P), max tokens, frequency and presence penalties
- Character search, favorites, and prompt blend / persona / character modes
- Browser HTTP tool with a private-network deny list and per-request write confirmation
- First-class semantic theme engine (8 families: Ember, Obsidian, Crimson, Cyberpunk, Forest, Lavender, Midnight, Paper; light & dark modes)
- 7 Vessel Orb Forms (Sphere, Torus, Prism, Wave, Morph, Flame, Crystal) with WebGL SDF shaders and interactive shape physics
- Reusable voice, persona, and generation profiles with inline chat badge
- In-app System Diagnostics & Telemetry modal (Web Audio, mic latency, catalog latency)
- Full Apache-2.0 open-source licensing and clear third-party notices
- GitHub CI/CD workflows (CI, Docs, CodeQL, Scorecard, Release) and repository branch ruleset

## Proposed & future enhancements

- Server-side DNS resolution checks for the HTTP tool
- Vision and multimodal attachment support in chat
- Enhanced syntax-highlighting library for markdown code blocks
- Voice cloning interface inside Ember (using Venice voice IDs)
- Peer-to-peer / local sync of chat sessions across devices
