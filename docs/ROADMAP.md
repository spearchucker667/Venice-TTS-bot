# Roadmap

No dates.

## Shipped in the current tree

- Streamed Venice chat with a system prompt
- Catalog refresh for text, speech, hearing, traits, characters, and compatibility hints
- Sentence-level speech playback with an MP3 fallback
- Speech-to-text microphone path and hands-free turn-taking
- Voice Changer quote, single queue, retrieve, and complete
- Local chat list with pin, rename, delete, export, and import
- Generation presets (temperature and top P), max tokens, frequency and presence penalties
- Character search, favorites, and prompt blend / persona / character modes
- Browser HTTP tool with a private-network deny list and per-request write confirmation

## Not shipped

- A chosen open-source license and a tagged release
- GitHub branch rules actually enforced on a remote
- Live status badges (no repository URL yet)
- Named maintainer in CODEOWNERS
- Server-side DNS checks for the HTTP tool
- Vision or file attachments in chat
- A syntax-highlighting library (fenced code is plain text)
- Voice cloning inside Ember (you can paste a voice id Venice already issued)
- Cloud sync of chats

## Proposed

- Confirm CI check names on the first GitHub run and then activate the ruleset
- Pick a license and fill in the copyright holder
- Keep the SBOM review as part of release, not only the direct-dependency table
