# Governance

This is a small project. There is no committee, and this workspace does not know the GitHub account that will own it.

## Until an owner is named

Whoever can administer the GitHub repository decides what merges, what is a release, and how a vulnerability report is answered. CODEOWNERS is intentionally unsigned until that account exists.

## After an owner is named

- That owner merges to the default branch and cuts tags.
- Security reports follow [SECURITY.md](SECURITY.md).
- A license choice is an owner decision, not a drive-by pull request. See [docs/LEGAL.md](docs/LEGAL.md).
- Adding another maintainer means updating CODEOWNERS and, if a second approval should be required, the ruleset. See [docs/BRANCH_PROTECTION.md](docs/BRANCH_PROTECTION.md).

## Contributors

Pull requests are welcome under [CONTRIBUTING.md](CONTRIBUTING.md). Merging is not automatic.
